# Будущие тесты

Тестирование — следующий отдельный этап. Сейчас автоматические тесты не добавлены
и CTest не подключён. Проверка сборки и запуска каркаса не является проверкой
алгоритмов симуляции.

План по SRS: AT-01 параметры, AT-02 контрольная поездка, AT-03 одновременные
вызовы, AT-04 вместимость, AT-05 границы, AT-06 управление, AT-07 повторяемость,
AT-08 нагрузка и учёт. При добавлении тестов подключить CTest и отдельную цель,
которая связывается с elevator::core.
